# Machine Produtora — website

Website for an audiovisual production studio: services, portfolio and contact.

**Live:** https://site-produtoramachine.vercel.app

## Stack

- React + TypeScript (Vite)
- Tailwind CSS + shadcn/ui (Radix UI)
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` if you need to set environment variables.
